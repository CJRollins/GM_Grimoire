# Starlight control prototype

This disposable one-chapter build establishes a navigation, table-of-contents,
typography, keyboard, and accessibility baseline for the custom Grimoire shell.
It consumes the same normalized `Character Options` content generated by
`scripts/extract-archive.mjs`; it is not the production reader.

Build it from the repository root with:

```powershell
npm.cmd run prototype:build
```

Its static output is written to `prototypes/starlight/dist/`.
